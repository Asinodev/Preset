Pertanyaan yang Sering Diajukan (FAQ)

Ya. Versi Kustom Pro (berbayar di Google Play Store) diwajibkan oleh pengembang aplikasi Kustom agar Anda dapat mengimpor file tema eksternal pihak ketiga.

Preset Asino dirancang menggunakan variabel skala global (Globals). Di dalam editor KLWP, masuk ke tab Globals, sesuaikan variabel scale atau padding atas-bawah sesuai lekukan kamera ponsel Anda.

Pastikan jumlah halaman di pengaturan Launcher (misal Nova Launcher) persis sama dengan jumlah halaman tema KLWP, dan opsi "Wallpaper Scrolling" di pengaturan Nova Launcher telah diaktifkan ("On" atau "Force").

Cukup unduh ulang file preset terbaru dari hub katalog ini, timpa file lama di penyimpanan, lalu muat ulang di KLWP. Jangan lupa menyimpan perubahan.
